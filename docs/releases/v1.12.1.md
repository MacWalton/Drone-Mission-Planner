# Drone Mission Planner v1.12.1

## Downloads

| File | For | Install |
|---|---|---|
| `drone_mission_planner_qgis.zip` | QGIS 3.22+ and QGIS 4 | *Plugins ▸ Manage and Install Plugins ▸ Install from ZIP* |
| `DroneMissionPlanner_ArcGISPro.zip` | ArcGIS Pro 2.9+ | Unzip, then *Catalog ▸ Toolboxes ▸ Add Toolbox* ▸ `DroneMissionPlanner.pyt` |

## Fixed

- **ArcGIS Pro: `AttributeError: 'Mission' object has no attribute 'coverage'`.** After updating, ArcGIS Pro could keep running the older planning engine it already had in memory, or pick up another copy elsewhere on its Python path.
  - The toolbox now always loads the `dronemapper_core` folder that sits next to it.
  - If the engine version doesn't match the toolbox, you get a clear message explaining what to replace.
- The QGIS plugin does the same, so updates and Plugin Reloader always use the bundled engine.

## Updating in ArcGIS Pro

1. Close ArcGIS Pro.
2. Replace the whole `DroneMissionPlanner` folder (the `.pyt` **and** its `dronemapper_core` folder) with the one from the zip.
3. Start ArcGIS Pro again. If the toolbox was already added, it picks up the new version.

Everything from 1.12 is included: automatic airspace, mission footprint outline, optional individual footprints, red take-off dots.

# Drone Mission Planner v1.8.0

## Downloads

| File | For | Install |
|---|---|---|
| `drone_mission_planner_qgis.zip` | QGIS 3.22+ and QGIS 4 | *Plugins ▸ Manage and Install Plugins ▸ Install from ZIP* |
| `DroneMissionPlanner_ArcGISPro.zip` | ArcGIS Pro 2.9+ | Unzip, then *Catalog ▸ Toolboxes ▸ Add Toolbox* ▸ `DroneMissionPlanner.pyt` |

## New in 1.8

- **Mission report as PDF**: choose *Mission report / field brief (.pdf)* when exporting.
  - Opens in any PDF reader on a phone, tablet or PC, prints on A4, and can be emailed to the client or crew.
  - Contents: summary, mission map with basemap and section maps, payload, launch stations, the flight and battery plan with tick boxes, terrain check and elevation profile, warnings, and page numbers.
  - Maps are vector graphics.
  - Made in plain Python, so it works the same in QGIS and ArcGIS Pro with nothing extra to install.
  - The interactive HTML field brief is still available.
- **Wind speed in knots** by default; m/s or km/h can be selected. The aircraft's max wind uses the same unit, and switching converts the numbers already entered. The report and brief show both, e.g. "14 kn (7.2 m/s)".
- **DJI Enterprise aircraft**: all have DJI's published camera, battery and flight-time specs, plus the DJI route-file aircraft and payload codes so Pilot 2 / FlightHub 2 accept the route.
  - Matrice 4E and 4T.
  - Dock aircraft: Matrice 4D/4TD (Dock 3) and 3D/3TD (Dock 2).
  - Mavic 3E, 3T and 3M.
  - Matrice 30 and 30T.
  - Matrice 350 RTK and Matrice 300 RTK, each with Zenmuse P1 or L1; the Matrice 350 RTK also with L2.
  - Matrice 400 with P1, L2 or L3.
  - Where DJI hasn't published a code (Matrice 400, L2/L3), you're asked for a route made on the aircraft in Pilot 2, and its codes are copied.

## Notes

- Flight times for aircraft carrying a gimbal camera are DJI's no-payload time scaled for the camera's weight. Edit them once you have your own figures.
- Not yet tested against a licensed ArcGIS Pro or flown on real aircraft. Please report anything odd.

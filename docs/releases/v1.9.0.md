# Drone Mission Planner v1.9.0

## Downloads

| File | For | Install |
|---|---|---|
| `drone_mission_planner_qgis.zip` | QGIS 3.22+ and QGIS 4 | *Plugins ▸ Manage and Install Plugins ▸ Install from ZIP* |
| `DroneMissionPlanner_ArcGISPro.zip` | ArcGIS Pro 2.9+ | Unzip, then *Catalog ▸ Toolboxes ▸ Add Toolbox* ▸ `DroneMissionPlanner.pyt` |

## New in 1.9

- **Image footprints**: the ground area each photo covers, so you can check overlap and coverage before you fly.
  - Shown as the **Image footprints** layer in QGIS, and as a `_footprints` feature class in ArcGIS Pro.
  - Each footprint is outlined in its flight's colour.
  - Placed where the camera actually fires along the planned flights, including stop-and-shoot hover points, and turned to the flight direction.
  - Sized for the height above ground at each photo. With a DEM, footprints shrink over hills and grow over valleys.
  - Attributes: flight, photo number, height above ground, GSD, footprint size and heading. Style by GSD to see how resolution changes over terrain.
- Photo centres now come from the same calculation, so their numbering matches the footprints.

Includes everything in 1.8: PDF mission report, wind in knots, DJI Enterprise aircraft.

## Notes

- Footprints assume a straight-down camera (gimbal −90°).
- Not yet tested against a licensed ArcGIS Pro or flown on real aircraft. Please report anything odd.
